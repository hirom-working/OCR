# スキャナー × AI：スキャンした書類を「本当に使える」デジタル資産へ

スキャナーで取り込んだPDF、そのまま眠っていませんか？

最新のAI技術（OCRと大規模言語モデル）を組み合わせ、スキャン後の「文字埋め込み・整理・リネーム」を完全自動化するツールを作成しました。


## 1. 課題：スキャンPDFの悩み

「紙をなくしてスッキリしたい」と思ってスキャナーを買ったものの、こんな悩みを持っていませんか？

**中身が検索できない**
ただの「画像」として保存されるため、後からキーワードで探せない。

**ファイル名が適当**
「Scan_20240121.pdf」のような名前になり、中身を開くまで何かわからない。

**整理が面倒**
スキャンした後に手動で名前を変えたり、フォルダ分けするのが大変で、結局「取り込みフォルダ」に溜まったまま。


## 2. 解決策：OCR + LLMで全自動化

このツールを使えば、**スキャンして待つだけ**で面倒な作業がすべて完了します。

**全文検索に対応**
高精度なOCR（文字認識）で、PDF内の文字を検索可能にします。

**自動リネーム**
AIが内容を読み取り、「[夏目漱石] こころ.pdf」のように適切なファイル名を自動で付けます。

**自動整理**
処理が終わったファイルは、指定した「電子図書」フォルダへ自動的に移動します。


## 3. 仕組み：処理の流れ

PCの裏側では、以下のようなリレー形式で処理が行われます。

<!-- ここにフロー図の画像を挿入 -->

**① スキャン**
スキャナーでPDFを作成し、監視フォルダに保存します。

**② 自動検知**
フォルダにPDFが入ると、自動で処理がスタートします。

**③ OCR（文字認識）**
GPUサーバーに送り、「Surya」という最新エンジンで文字を読み取ります。

**④ テキスト埋め込み**
読み取った文字情報をPDFに埋め込み、検索可能にします。見た目は変わりませんが、文字を選択したり検索したりできるようになります。

**⑤ 情報抽出**
LLM（大規模言語モデル）が本文を読み、タイトルと著者を推測します。

**⑥ リネーム＆移動**
「[著者] タイトル.pdf」または「タイトル.pdf」に名前を変更し、出力フォルダへ移動します。作業用ファイルは自動で削除されます。


## 4. こだわりポイント

**高精度OCR「Surya」の採用**

従来のOCRソフト（Tesseract等）よりもレイアウト認識に優れ、日本語を含む多言語に対応した最新のAIモデルです。GPUを使うことで高速かつ正確に文字をデータ化します。

**LLMによる「文脈」理解**

単に一行目をファイル名にするのではなく、LLM（大規模言語モデル）が文書の冒頭やメタデータを読み、「何がタイトルで、誰が著者か」を人間のように判断します。

**環境に依存しない設計**

設定ファイルを書き換えるだけで、サーバー構成やフォルダパスが変わっても柔軟に対応できます。別の環境への移植も容易です。


## 5. 必要なもの・始め方

### 必要な環境

**必須**
- スキャナー（ScanSnap等、PDF保存できるもの）
- ホストPC（Mac または Linux）
- Python 3.11以上

**推奨**
- GPUサーバー（NVIDIA GPU搭載マシン）
- Ollamaサーバー（LLMを動かす環境）

GPUサーバーがなくてもCPUで動作しますが、処理速度が大幅に低下します。GPUサーバーとOllamaサーバーは同一マシンでも構いません。

### セットアップ

1. リポジトリをクローン
2. Python環境をセットアップ
3. 設定ファイルを作成（サンプルをコピーして編集）
4. 監視スクリプトを起動

あとはスキャナーでスキャンするだけです。

詳しいセットアップ手順はGitHubリポジトリのREADMEをご覧ください。

https://github.com/hirom-working/OCR
